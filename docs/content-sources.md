# Learning content sources

Checked on 2026-10-19. The Russian explanations, translations, task wording and teaching sentences in this project were authored for this application. Reference links support grammatical facts and lexical forms; no source lesson or exercise collection is redistributed.

| Primary reference | Verification scope |
| --- | --- |

The A1–C2 labels are this application's teaching sequence, not an exhaustive examination syllabus or a certification of learner ability. The expanded course retains the original 48 cards and 14 topics, with their IDs and original exercises unchanged. The 35 grammar topics contain 210 practice exercises and 105 independent final questions. Each topic includes an explanation, reference table and German/Russian examples. Broad grammatical rules have deliberately limited examples; the answer checker compares accepted course answers and does not claim unrestricted linguistic analysis. Offline listening requires a German voice explicitly reported by the operating system as local.

The expansion's lexical and grammar provenance, checked references and scope notes are recorded in [vocabulary sources](vocabulary-sources.md) and [grammar sources](grammar-sources.md). All added explanations, exercise sentences and Russian translations are original teaching content. They are shipped with the application and require no runtime network connection.

Version 1.1.0 contains 360 vocabulary cards: 60 each for A1, A2, B1, B2, C1 and C2. The 312 expansion cards are separate additive seeds; the 48 original records retain their IDs, content and order. Grammar topic counts are A1: 7, A2: 7, B1: 7, B2: 5, C1: 5 and C2: 4.
